# Flags

Shown on the home page next to each region.

- `be-vlg.svg` (Flanders) and `be-wal.svg` (Wallonia): the official regional flags, from
  Wikimedia Commons ([Flag of Flanders](https://commons.wikimedia.org/wiki/File:Flag_of_Flanders.svg),
  [Flag of Wallonia](https://commons.wikimedia.org/wiki/File:Flag_of_Wallonia.svg)), shrunk
  with svgo. Their licence is the one on those Commons pages.
- `be-bru.svg` (Brussels-Capital Region): redrawn for this site after the official flag.
- `be.svg` (Belgium): the black, yellow and red tricolour, drawn for this site.
